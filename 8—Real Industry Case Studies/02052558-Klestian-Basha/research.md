# Research – Topic 8: Real Industry Case Studies

## AI in Modern Software Engineering

Artificial Intelligence has become an important part of software engineering. Rather than replacing software engineers, AI is helping developers write code faster, detect bugs, generate documentation, and automate repetitive tasks. Many technology companies have integrated AI into their development workflows to improve productivity while keeping engineers responsible for reviewing and testing the final software.

## Microsoft

Microsoft has invested heavily in AI-assisted software development through GitHub Copilot. Developers use Copilot to generate code suggestions, explain existing code, and create unit tests. This reduces time spent on repetitive coding tasks and allows engineers to focus on software architecture and problem solving. However, developers must still review AI-generated code because it can contain bugs or security issues.

## Google

Google uses AI across many engineering activities. AI assists with code review, testing, documentation, and cloud services. Google also develops Gemini, which helps developers understand code, generate code snippets, and solve programming problems. Engineers remain responsible for validating outputs and ensuring software quality.

## Shopify

Shopify encourages employees to use AI tools during software development. AI is used to speed up coding, documentation, and knowledge sharing. By automating repetitive work, developers have more time for designing features and improving customer experience. Human review is still essential before releasing software.

## Duolingo

Duolingo integrates AI to improve both software development and its language-learning platform. AI helps engineers create new features more quickly and supports personalized learning experiences for users. Developers continue to monitor performance and improve AI-generated results.

## Advantages of AI in Software Engineering

- Faster code generation.
- Improved developer productivity.
- Better documentation support.
- Assistance with debugging and testing.
- Reduced time spent on repetitive tasks.

## Limitations and Challenges

- AI can generate incorrect or insecure code.
- Outputs may contain outdated practices.
- Engineers may become too dependent on AI.
- Human review, testing, and critical thinking remain necessary.

## Conclusion

Real industry examples show that AI is changing software engineering rather than replacing engineers. Companies such as Microsoft, Google, Shopify, and Duolingo use AI to increase efficiency while relying on skilled software engineers to make final decisions, ensure quality, and solve complex problems.
